# family-news

Archived family newsletters, holiday cards, and photo galleries.

Live site: https://newsletters.jljcd.com/

## Photo galleries

Photo pages (`*/photos.html`) share a simple lightbox gallery:

- `gallery.css` — grid layout and lightbox styles
- `gallery.js` — click-to-open lightbox with prev/next/keyboard navigation
- each gallery's `photos.html` contains the figures and captions for that event

Galleries include:

- `chess/` — Carl's chess tournament
- `eagle-creek/` — Eagle Creek hike
- `the-ridge/` — hike onto the ridge
- `vancouver-island/` — British Columbia
